# Fresh Oranges API

This repository contains the API portion of a larger movie review web application. The final application is a project for my Web Application Programming course at NSCC.

## Overview

The Fresh Oranges API provides the data layer behind the platform. It exposes the movies, genres, reviews and user data that the public site and the [admin site](https://github.com/MaxGazley/MoviesAdmin) rely on.

This project is part of a larger Web Application Programming assignment focused on building a full-stack application for movie reviews, with this repository handling the back-end functionality.

## Features

- RESTful endpoints for all movies, and movie by id
- User account info stored with every review
- Hides reviews that are not published
